# Anno GUI Studio experimental release

Extract the Windows x64 ZIP and run anno-gui-studio.exe with Microsoft Edge WebView2 installed. Supply your own Anno 1404 Venice or History game directory and unpacked RDA Explorer dependencies on first launch. STANDALONE.md has the complete setup instructions.

The editor reads archive copies and saves separate working copies. It does not install edits into the game. History archive discovery is supported; broad History rendering parity remains unverified. Preview fidelity and archive-precedence limitations remain experimental.

ZIP checksums are in SHA256SUMS.txt. Packages contain GPL-3.0-only project code; corresponding source and build instructions are available in this release's tag archive. Game resources and RDA Explorer binaries are not included.
