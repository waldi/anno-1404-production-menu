# Production Menu experimental release

Choose the GOG Gold/Venice x86 archive for Addon.exe 2.01.5010 or the Ubisoft History/Venice x64 archive for Anno1404Addon.exe 4.0.4253.0. Exact executable SHA256 fingerprints are recorded in package.json; unknown builds are rejected.

Close the game, back up any existing d3d9.dll, then copy the DLL, companion and two dialog files next to the matching executable. History also needs ANNORE_HISTORY_NATIVE.flag. Use DirectX 9 mode; Ctrl+Q toggles Production. To remove, close the game, remove only installed package files and restore any previous proxy.

Current/potential rates estimate production, not measured deliveries. Full warehouses, unavailable inputs and broader gameplay/lifecycle behavior remain limitations. Both native panels are experimental.

ZIP checksums are in SHA256SUMS.txt. Packages contain GPL-3.0-only project code; corresponding source and build instructions are available in this release's tag archive. No game resources are included.
