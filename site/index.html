Install & play.

No compiling. No developer tools. Just your game and the matching ZIP.

  1. 01

    Close the game & unpack

    Download your edition’s ZIP and extract it. If the game folder already has a d3d9.dll, back it up first; another mod may use it.

  2. 02

    Copy beside the game executable

    Find the folder containing Addon.exe or Anno1404Addon.exe. Copy these four files directly into it:

    • d3d9.dll
    • AnnoRECompanion.exe
    • production_dialog_v5.dlg
    • production_button.dlg

    History Edition: also copy ANNORE_HISTORY_NATIVE.flag into that folder.

  3. 03

    Start Venice in DirectX 9 mode

    Load your game and press Ctrl + Q to open or close Production. The companion starts automatically. Select a settlement, or Ctrl-click several to combine them.

Plan with estimates.

Current and potential production rates are estimates, not measured deliveries. Full warehouses or missing inputs can prevent actual output. Both edition packages remain experimental.

Before you sail

A little help.

The menu doesn’t open. What should I check?

Check that you downloaded the correct edition, your executable version is supported, and the game is running in DirectX 9 mode. The files should sit beside the executable, not inside an extra extracted folder. History Edition also needs the activation flag. Then load a game and press Ctrl+Q.

How do I uninstall it?

Close the game and remove only the mod files you copied. Restore your previous d3d9.dll if you backed one up. You don’t need to remove your saved games.

Do I need GUI Studio, Python or Ghidra?

No. Those tools are for development and research. Installing the mod only requires your supported game and the matching Production Menu ZIP.

Where can I report a problem?

Open an issue on GitHub with your game edition, executable version and a description of what happened. A screenshot can help.
